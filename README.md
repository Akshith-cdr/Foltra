# FOLTRA - AI Crop Health Monitoring

An AI-driven crop health monitoring system that leverages computer vision and deep learning to detect crop diseases, localize affected regions, estimate disease severity, and identify early indicators of crop health risks.

## Overview

Crop diseases are a major challenge in agriculture, often leading to significant yield and economic losses when detection is delayed. This project aims to develop an intelligent, vision-based system capable of analyzing plant images and providing reliable information about crop health.

Rather than limiting the system to disease classification, the project focuses on a broader crop health assessment pipeline, including disease localization, severity estimation, robustness to real-world field conditions, and temporal analysis for monitoring changes in crop health over time.

## Objectives

* Detect and classify crop diseases using deep learning.
* Localize diseased regions within plant images.
* Estimate the severity of detected diseases.
* Improve model robustness under real-world field conditions.
* Analyze crop health changes across time.
* Develop an early-risk detection framework for potential crop health problems.
* Integrate the developed models into a practical crop monitoring system.

## Project Roadmap

The project is being developed progressively, beginning with problem definition, dataset preparation, and baseline computer vision models. Subsequent stages focus on robustness, disease localization, severity estimation, temporal modeling, contextual information, research validation, and system integration.
